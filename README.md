# 淘宝用户行为预测模型 (基于 Stacking 集成学习)

本项目基于阿里巴巴天池工业级数据集，通过对一亿条用户行为日志进行深度特征工程，预测用户在特定日期是否产生购买行为。

## 🎯 建模目标
- **核心任务**：基于用户在一定时间窗口内的历史行为数据（PV, Fav, Cart, Buy），构建特征向量，预测该用户在目标期内是否会**发生购买行为**。
- **目标变量 (Y)**：二分类变量。若用户发生购买行为，则记为 **1**，反之记为 **0**。

## 💾 数据来源 (Data Source)
本项目原始数据来源于 **阿里巴巴天池 (Aliyun Tianchi)**。
* **数据集名称**: UserBehavior (淘宝用户行为数据集)
* **下载链接**: [https://tianchi.aliyun.com/dataset/649](https://tianchi.aliyun.com/dataset/649)
* **数据集规模**: 包含约 1 亿条用户行为记录，涵盖约 100 万用户及 416 万件商品。
* **核心字段**:
    - `User_ID`: 用户唯一标识
    - `Item_ID`: 商品唯一标识
    - `Category_ID`: 商品类目唯一标识
    - `Behavior_Type`: 行为类型（pv: 浏览, buy: 购买, cart: 加购, fav: 收藏）
    - `Timestamp`: 行为发生的时间戳

## 📅 数据集切分逻辑 (滑动窗口法)
本项目强调使用**全量未过滤**（完整保留了 $PV \le 5$ 的样本）的原始数据构建特征矩阵，以保留最真实的用户行为分布。

| 数据集类型 | 特征观察窗口 (Feature Window) | 目标预测日 (Target Label) | 样本状态 |
| :--- | :--- | :--- | :--- |
| **训练集 (Train)** | 2017/11/25 – 2017/12/01 | 2017/12/02 | 全量未过滤 |
| **测试集 (Test)** | 2017/11/26 – 2017/12/02 | 2017/12/03 | 全量未过滤 |



## 📊 项目核心亮点
1. **深度特征工程**：自主构造了 **25 个核心特征**。涵盖基础统计计数、时序衰减特征以及基于拉普拉斯平滑处理的转化率指标（如加购/浏览比），从多维度刻画用户购买意向。
2. **类别不平衡的系统性解决**：针对正负样本 **1:4.6** 的极端分布，本项目并未盲目采用简单的采样，而是通过**代价敏感学习 (Cost-sensitive Learning)**。在 SVM、随机森林中引入 `class_weight='balanced'`，在 XGBoost 中配置 `scale_pos_weight`。实验证明，该策略将**召回率从不足 1% 提升至 58% 左右**。
3. **多维度网格搜索调参**：利用 `GridSearchCV` 配合 **5 折交叉验证** 对集成树的深度、学习率及叶子节点数等参数进行了精细化搜索，有效防止了模型在海量噪声数据中的过拟合现象。

## 📁 仓库结构说明
- **`data/`**: 存放数据下载链接及格式对齐的训练集/测试集 Sample 样例。
- **`notebooks/`**: 包含全流程实验代码：EDA、特征工程、调参、Stacking 模型训练，全部集成在 **`Python_final.ipynb`**。
- **`models/`**: 存放经过 GridSearchCV 调参后的最优模型文件 (`.joblib` / `.pkl`)。
- **`README.md`**: 项目主说明文档。

## 🛠️ 环境依赖与复现说明
1. **依赖环境**: 建议使用 Python 3.8+，核心依赖库包括：`pandas`, `numpy`, `scikit-learn`, `lightgbm`, `xgboost`, `matplotlib`, `seaborn`, `joblib`。
2. **复现步骤**:
    - 从天池链接下载原始数据 `UserBehavior.csv.zip` 并解压，将其置于项目根目录。
    - 确保 `data/` 目录下存在样例数据以供代码逻辑校验。
    - 运行 `notebooks/Python_final.ipynb` 即可完成从数据处理到模型融合的全流程复现。
