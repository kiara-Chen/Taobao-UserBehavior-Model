# 淘宝用户行为预测模型 (基于 Stacking 集成学习)

本项目基于阿里巴巴天池工业级数据集，通过对一亿条用户行为日志进行深度特征工程，预测用户在特定日期是否产生购买行为。

## 🎯 建模目标
- **核心任务**：基于用户在在一定时间窗口内的历史行为数据（PV, Fav, Cart, Buy），构建特征向量，预测该用户在目标期内是否会**发生购买行为**
。
- **目标变量 (Y)**：二分类变量。若用户在目标预测日发生购买行为记为 **1**，反之记为 **0**。

## 📊 项目核心亮点
1. **深度特征工程**：自主构造了 25 个核心特征，涵盖基础统计计数、时序衰减特征以及基于拉普拉斯平滑处理的转化率指标（如加购/浏览比），深度刻画用户意向。
2. **类别不平衡的系统性解决**：针对正负样本 **1:4.6** 的极端分布，放弃简单采样，采用**代价敏感学习 (Cost-sensitive Learning)**。在 SVM 与随机森林中引入 `class_weight='balanced'`，并在 XGBoost 中配置 `scale_pos_weight`。实验证明，该策略将**召回率从不足 1% 显著提升至 58% 左右**。
3. **多维度网格搜索调参**：利用 `GridSearchCV` 配合 **5折交叉验证**，对集成树的深度、学习率及叶子节点数等关键超参数进行精细化搜索，在海量噪声数据中精准捕捉结构风险最小化的平衡点，有效防止过拟合。

## 📁 仓库结构说明
- `data/`: 存放数据下载链接及格式对齐的训练集/测试集 Sample 样例。
- `notebooks/`: 包含全流程实验代码：EDA、特征工程、调参、Stacking 模型训练。
- `models/`: **存放经过 GridSearchCV 调参后的最优模型文件 (.joblib/.pkl)**。
- `README.md`: 项目主说明文档。

## 📅 数据集切分逻辑 (滑动窗口法)
本项目强调使用**全量未过滤**的原始样本构建特征矩阵，以保留完整的行为模式信息。

| 数据集类型 | 特征观察窗口 (Feature Window) | 目标预测日 (Target Label) | 样本状态 |
| :--- | :--- | :--- | :--- |
| **训练集 (Train)** | 2017-11-25 至 2017-12-01 | 2017-12-02 | 全量未过滤 |
| **测试集 (Test)** | 2017-11-26 至 2017-12-02 | 2017-12-03 | 全量未过滤 |

## 🛠️ 环境依赖与复现
1. **原始数据**: [天池 UserBehavior 数据集](https://tianchi.aliyun.com/dataset/649)。
2. **环境要求**: Python 3.8+, pandas, scikit-learn, lightgbm, xgboost, matplotlib, seaborn。
3. **快速开始**: 直接运行 `notebooks/` 下的脚本。系统将自动调用 `UserDatasetBuilder` 类生成特征，并可加载 `models/` 下的最优模型进行推理。
